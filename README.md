# このアプリは、どうやって組み合わせを決めているのか

「なんでまた自分だけ待機なの?」「さっきもこの人とパートナーだったのに」——
サークルや練習会の組み合わせでよくある不満を、できるだけ減らすために作られたアプリです。
専門的な話は抜きにして、考え方だけをシンプルに説明します。

---

## 目指していること(優先順位つき)

このアプリが組み合わせを決めるとき、次の3つを **この順番で** 大事にしています。

1. **試合数をなるべく揃える**(一番大事)
   誰か1人だけ試合数が多い/少ない、という不公平が起きないようにします。

2. **待機がなるべく連続しないようにする**
   1回待機したら、次はできるだけ優先的に試合に出られるようにします。

3. **パートナー・対戦相手をなるべくかぶらせない**
   同じ人とばかり組んだり対戦したりしないよう、色々な人と回るようにします。

大事なのは、この優先順位が **上から順に絶対** だということです。
「重複を避けるために誰かの試合数を犠牲にする」ということは絶対にしません。
公平性が最優先で、重複回避はその範囲内でできる限り頑張る、というスタンスです。

---

## どうやって「誰が出るか」を決めているか

毎試合、こんな考え方で8人を選んでいます。

> **「一番試合数が少ない人」から優先的に選ぶ。もし試合数が同じ人が並んだら、「一番長く待っている人」を優先する。**

たとえば12人中、Aさんが2試合・Bさんが3試合こなしていたら、次はAさんが優先されます。
Aさん・Cさんが同じ2試合で並んでいたら、より長く待っているほうが優先されます。

これを毎試合繰り返すだけで、自然と「試合数の差は最大でも1」「連続で待機することはほぼない」という状態が保たれます(※人数が多く、コートが2面しかない場合はどうしても待機が発生しますが、その待機がなるべく特定の人に偏らないようにしています)。

---

## どうやって「誰と組むか」を決めているか

出場する8人が決まったら、次は「2コート×パートナー」の組み合わせ方を決めます。

実は8人がいれば、コート分け・ペア分けの**組み合わせ方は300通り以上**あります。
このアプリは、その300通りすべてを一瞬で見比べて、

> **「まだ一度も組んだことのないペア・対戦したことのない相手」がなるべく多くなる組み合わせ**

を選びます。イメージとしては、名簿を見ながら「この2人はもう組んだことあるな…じゃあこっちの2人で」と、経験豊富な運営の人が頭の中で調整しているのと同じことを、機械が全パターン試して一番良いものを選んでいる、という感じです。

さらに、**「同じ2人が何度も繰り返し再会する」ことは特に強く避けます。** 仮にどうしても誰かと2回目の再会が避けられない状況でも、「Aさんは3回もBさんと当たっているのに、他の人は誰とも被っていない」というような偏りが起きないよう、複数の人に1回ずつ薄く分散させる工夫をしています。

---

## それでも重複が起きてしまうことがある理由

人数が少ないのに試合数が多いと、数学的にどうしても同じ人と再会せざるを得ない場面が出てきます。

たとえば9人しかいないのに10試合もこなすと、1人あたり8〜9試合はプレーすることになります。でも、パートナーになれる相手は最大でも「自分以外の8人」しかいません。つまり9試合目には、必ず誰かと2回目のペアを組むことになる——これは組み合わせの工夫でどうにかできる話ではなく、**人数と試合数の掛け算で決まる、避けようのない上限**です。

このアプリはその上限の中で最大限工夫していますが、「絶対に0回」を保証できるわけではないことは、あらかじめご承知おきください。

## 画面に出てくる数字の見方

結果画面の「公平性チェック」には、次の指標が出ます。

| 表示項目 | 意味 |
|---|---|
| **試合数の差** | 一番多くプレーした人と、一番少なかった人の差。0か1なら理想的です。 |
| **パートナーの再会**(総回数/深度) | 総回数＝同じパートナーと2回目以降で組んだ回数の合計。深度＝その中で一番多く再会したペアが何回"超"再会したか。深度が低いほど、重複が特定のペアに集中していないということです。 |
| **対戦相手の再会**(総回数/深度) | 考え方はパートナーと同じで、対戦相手バージョンです。 |
| **2連続待機**(総回数/深度) | 2回以上連続で待機してしまった回数と、その中で一番長く連続した回数です。 |

色分けも同じ考え方で、組み合わせ表の中で

- 🟠 オレンジの番号＝そのペアはパートナーとして**再会**している
- 🟣 紫の番号＝その対戦は対戦相手として**再会**している
- 🔴 赤の番号＝**2回連続**で待機している

とひと目でわかるようにしています。

---

## まとめ

一言でいうと、このアプリは「**試合数の公平さを絶対に守った上で、可能な限りいろいろな人と組み合わせる**」という、大会運営のベテランが頭の中でやっているであろう調整を、全パターン計算して機械的に再現しているだけです。魔法のような複雑なことはしておらず、やっていることは意外とシンプルです。
